# FamilySpace index Apple식 단순화 전략

## 결론
index.html은 모든 내용을 보여주는 대시보드가 아니라 Apple.com처럼 “한 섹션에 한 메시지”를 전달하는 입구가 되어야 한다. 상세 정보는 dad/mom/baby/blog/guide 링크로 넘긴다.

## 최종 섹션 구조
1. Compact nav
   - FamilySpace
   - 생활
   - 육아
   - 서류
   - 이야기
   - KR / VI / 中文 작은 토글

2. Hero
   - 한 메시지: “베트남에서 가족으로 사는 하루를 덜 복잡하게”
   - 설명 1줄
   - CTA 2개: 생활 가이드 보기 / 가족 이야기 보기
   - 장식은 최소화. 움직임은 배경 1개 이하.

3. 핵심 카테고리 4개
   - 체류·서류: TRC, 비자, 행정 준비
   - 생활비·정착: 월 지출, 마트, 병원, 교통
   - 육아·병원: 식단, 병원, 놀이, 성장 기록
   - 주말·이야기: 가족 코스, 일기, 문화 차이

4. 처음 온 사람이 많이 보는 글 3개
   - 각 카드에는 제목 1줄, 설명 1줄, 링크만 둔다.

5. 짧은 신뢰/업데이트
   - 실제 한-베 가족 생활 기준
   - 업데이트 날짜
   - 비자/의료 정보는 공식 확인 필요

## 링크 구조
- 생활비/정착 → dad.html
- 육아/식단/병원 → mom.html 또는 baby.html
- 체류/서류 → dad.html#visa 또는 향후 guide 페이지
- 가족 이야기 → blog.html
- 주말/별보기 → stars.html 또는 향후 route page

## 디자인 방향
Apple처럼 넓은 여백, 단순한 색, 큰 제목, 짧은 문장, 링크 중심을 사용한다. 단, FamilySpace는 가족 사이트이므로 완전한 흑백보다 따뜻한 연회색/베이지를 조금 섞는다.
