# FamilySpace index.html 재미 구조 개선 제안: 실용 + 상호작용

작성 목적: 현재 테스트용 `index.html`을 직접 수정하지 않고, 첫 화면에서 “뭐지? 눌러볼까?”라는 감각을 만들 수 있는 실용형 재미 요소를 제안한다. 핵심은 신뢰를 버린 게임화가 아니라, 실제 한-베 가족 생활 문제를 작은 선택·퀴즈·미션·비교 경험으로 바꾸는 것이다.

## 0. 현재 페이지 진단

현재 `index.html`은 이미 시각적으로 많이 개선되어 있다. 히어로 영역, 빠른 카드, 오늘의 Family Lab, 미션 오빗, 리빌 카드, 체크리스트, 비교표, 다음 클릭 루프가 존재한다. 하지만 사용자가 “재미없어 보인다”고 느낄 수 있는 이유는 다음과 같다.

1. 상호작용이 ‘결과를 바꾸는 행동’처럼 느껴지지 않는다.
   - 버튼을 눌러도 실제 점수, 추천, 다음 선택, 개인화 결과가 없다.
   - “카드에 마우스를 올리면 설명이 바뀐다” 수준이라 체험보다 설명에 가깝다.

2. 방문자 자신을 끌어들이는 질문이 약하다.
   - 현재 문구는 “우리가 이런 정보를 정리합니다”에 가깝다.
   - 더 강한 첫 질문은 “당신 가족은 지금 어떤 상황인가요?” 또는 “이번 달 생활비 괴물은 어디에 숨어 있나요?”처럼 방문자 상태를 바로 묻는 형태다.

3. 숫자·선택·놀람 포인트가 부족하다.
   - 생활비, 병원, 식단, 비자 같은 주제는 원래 재미보다 불안이 큰 주제다.
   - 재미를 만들려면 “3문항만 답하면 추천 루트”, “우리집 이번 달 위험 지점”, “한국 vs 베트남 체감 슬라이더”처럼 작고 즉각적인 피드백이 필요하다.

4. 캐릭터성이 아직 배경 장식에 머문다.
   - 한국인 아빠, 베트남 엄마, 25개월 아기라는 강한 자산이 있지만 첫 화면에서 ‘가족 캐릭터가 말을 거는 느낌’은 약하다.
   - 정보 카드보다 “아빠의 돈 걱정”, “엄마의 식단 감각”, “아기의 오늘 컨디션”처럼 역할별 추천이 더 기억에 남는다.

5. 다국어 방문자를 위한 재미가 ‘번역’에 가깝다.
   - KR/VI/中文 전환은 좋지만, 세 언어권 모두가 직관적으로 이해할 공통 장치가 더 필요하다.
   - 숫자, 아이콘, 선택지, 지도, 체크 상태, 점수, 비교 막대는 언어 장벽을 낮추면서 재미를 만든다.

## 1. 정보형 페이지와 탐색/엔터테인먼트형 페이지의 차이

정보형 페이지는 방문자가 읽어야 가치가 생긴다. 탐색형 페이지는 방문자가 누르는 순간 가치가 생긴다.

| 구분 | 정보형 페이지 | 탐색/상호작용형 페이지 |
|---|---|---|
| 첫 반응 | “읽어봐야 알겠다” | “하나 눌러볼까?” |
| 방문자 역할 | 독자 | 선택자/참여자 |
| 콘텐츠 구조 | 카드, 문단, 표 | 질문, 결과, 단계, 변화 |
| 체류 이유 | 필요한 정보 | 내 상황에 맞는 답을 찾는 과정 |
| 재방문 이유 | 새 글 확인 | 오늘의 미션, 체크 상태, 비교 업데이트 |
| 신뢰 장치 | 출처, 날짜, 경험 | 결과 설명 + 주의 문구 + 자세히 보기 링크 |

FamilySpace는 순수 게임 사이트가 되면 안 된다. 대신 “가족 생활 문제를 30초짜리 작은 진단과 선택 경험으로 바꾸는 사이트”가 되어야 한다.

## 2. FamilySpace에 맞는 재미의 정의

FamilySpace에 맞는 재미는 유치한 게임이 아니라 다음 5가지다.

1. 생활 밀착형 재미
   - “이번 달 생활비 괴물 찾기”
   - “오늘 아기 식단 룰렛”
   - “주말 가족 코스 고르기”

2. 비교에서 오는 재미
   - 한국 vs 베트남 비용·병원·마트·주말 루틴 비교
   - 내 선택에 따라 막대그래프나 카드 결과가 바뀌는 구조

3. 캐릭터 선택 재미
   - 아빠 모드: 돈, 비자, 보험, 장보기
   - 엄마 모드: 식단, 컨디션, 루틴, 힐링
   - 아기 모드: 놀이, 낮잠, 병원, 성장

4. 미션 완료 재미
   - 체크리스트를 단순 목록이 아니라 “오늘 3개만 끝내기”로 제시
   - 완료할수록 결과 문구와 다음 링크가 바뀜

5. 발견형 재미
   - 카드 뒤집기, 오늘의 질문, 랜덤 미션, 지도 핀 선택
   - 단, 결과는 항상 실제 가이드/체크리스트로 이어져야 한다.

## 3. 한국/베트남/중국어권 모두에게 통할 재미 원칙

1. 텍스트보다 선택지 중심
   - 긴 농담이나 언어유희는 번역에서 약해진다.
   - “돈 / 아기 / 서류 / 주말” 같은 큰 선택지는 세 언어권 모두 이해하기 쉽다.

2. 숫자와 아이콘 활용
   - 생활비, 병원, 거리, 시간, D-day는 언어보다 직관적이다.
   - 예: `D-60 TRC`, `3분 체크`, `₩ ↔ ₫`, `0~5단계 안심 점수`.

3. 가족 상황 공감
   - 국제가족, 아이, 병원, 마트, 서류, 예산은 문화권을 넘어 공통 고민이다.
   - 과장된 밈보다 “맞아, 우리도 이거 필요해”가 더 강하다.

4. 신뢰 보존
   - 의료·비자·금융은 “경험 기반”, “공식 확인 필요”, “최근 업데이트” 라벨을 유지한다.
   - 결과 화면에는 반드시 “자세한 가이드 보기”와 “개인 상황에 따라 확인 필요”를 넣는다.

## 4. 바로 테스트할 수 있는 재미 요소 TOP 5

### TOP 1. 3문항 생활비 괴물 찾기 퀴즈

- Visitor intent: “베트남에서 살면 정말 한국보다 싼가?”, “우리집 돈이 어디서 새지?”
- Retention mechanism: 3개 선택 후 즉시 결과 카드 표시
- Concrete section/card title: `이번 달 생활비 괴물은 어디에 숨어 있을까?`
- Why it increases dwell time: 방문자가 자기 상황을 입력하면 결과를 기다리게 되고, 결과 후 생활비 보드로 이동할 이유가 생긴다.
- Suggested visual asset: 귀엽지만 과하지 않은 ‘생활비 괴물’ 아이콘 4종: 집세 괴물, 마트 괴물, 병원 괴물, 송금 괴물
- Future monetization angle: 생활비표 아래 미래 광고 슬롯, 국제송금/가계부/마트 비교 가이드 제휴 가능
- Risk/trust note: 실제 절약 보장처럼 말하지 말고 “가족 경험 기반의 점검용”으로 표시

구성 예시:

```text
Q1. 이번 달 가장 부담되는 항목은?
[집세] [마트] [병원] [아기용품] [송금]

Q2. 한국과 비교했을 때 베트남 생활비는?
[확실히 저렴] [비슷함] [생각보다 비쌈] [아직 모르겠음]

Q3. 지금 가장 필요한 것은?
[예산표] [마트 비교] [병원비 준비] [송금 루틴]

결과: 우리집 생활비 괴물은 ‘마트+아기용품형’입니다.
다음 행동: K-Market/WinMart 장보기 비교표 보기 → dad.html 또는 생활비 가이드
```

첫 화면 적용 위치: 현재 히어로 오른쪽 `처음 온 가족이 많이 찾는 것` 카드 또는 `mission-orbit` 앞.

### TOP 2. 오늘의 한-베 가족 미션 카드

- Visitor intent: “오늘 뭘 먼저 보면 되지?”
- Retention mechanism: 매일/새로고침마다 1개 미션 카드 표시, 완료 체크 가능
- Concrete section/card title: `오늘의 가족 미션: 3분 안에 하나만 끝내기`
- Why it increases dwell time: 정보 탐색을 할 일처럼 바꾸면 방문자가 페이지와 상호작용한다.
- Suggested visual asset: 스탬프 카드 UI, 완료 도장, 가족 캐릭터 작은 말풍선
- Future monetization angle: 미션 완료 후 관련 체크리스트/가이드/미래 광고 슬롯 연결
- Risk/trust note: 비자·의료 미션은 반드시 공식 확인 필요 라벨 표시

미션 예시:

```text
오늘의 미션
[ ] TRC 만료일을 가족 캘린더에 적기
[ ] 아기 병원 후보 1곳 저장하기
[ ] 이번 주 마트 장보기 3개만 비교하기

완료하면: “오늘 FamilySpace 미션 1개 완료! 다음은 생활비 표를 볼까요?”
```

현재 체크리스트 섹션을 단순 리스트에서 “오늘 1개만 완료” 구조로 바꾸면 훨씬 덜 지루하다.

### TOP 3. 한국 vs 베트남 체감 비교 슬라이더

- Visitor intent: “한국이랑 베트남 생활이 실제로 얼마나 다르지?”
- Retention mechanism: 슬라이더를 움직이면 비용/편리함/불안 포인트 문구가 바뀜
- Concrete section/card title: `한국 ↔ 베트남 체감 온도 조절기`
- Why it increases dwell time: 표를 읽는 대신 손으로 비교를 조작하게 된다.
- Suggested visual asset: 좌측 KR, 우측 VN, 가운데 가족 아이콘이 움직이는 슬라이더
- Future monetization angle: 생활비표, 병원 준비물, 여행/마트 가이드 내부 링크와 결합
- Risk/trust note: “정확한 물가 통계”가 아니라 “우리 가족 체감 기준”이라고 명확히 표시

구성 예시:

```text
[한국 쪽] ----●---- [베트남 쪽]
주제 선택: [병원] [마트] [주말 놀이] [아기 외식]
결과: 베트남은 실내몰/카페 선택지가 편하지만, 위생·언어 체크가 먼저 필요해요.
```

현재 `한국 vs 베트남, 체감 차이` 표를 이 슬라이더 위젯으로 바꾸거나 표 위에 붙이면 좋다.

### TOP 4. 가족 캐릭터 모드 선택

- Visitor intent: “내가 관심 있는 관점으로 보고 싶다.”
- Retention mechanism: 아빠/엄마/아기/처음 온 가족 모드를 누르면 추천 카드가 바뀜
- Concrete section/card title: `누구 시선으로 볼까요?`
- Why it increases dwell time: 방문자가 자신의 역할을 선택하고, 페이지가 반응한다고 느낀다.
- Suggested visual asset: 4개 캐릭터 토글 카드: 아빠=계산기, 엄마=식탁, 아기=블록, 처음 온 가족=지도
- Future monetization angle: 각 모드별 내부 링크 체류 루프 강화. 장기적으로 뉴스레터/무료 가이드 CTA 배치 가능
- Risk/trust note: 가족 구성 고정관념처럼 보이지 않게 “역할은 바꿔 선택 가능” 문구 추가

구성 예시:

```text
누구 시선으로 볼까요?
[아빠: 생활비/서류] [엄마: 식단/루틴] [아기: 놀이/성장] [처음 온 가족: 필수 체크]

선택 결과:
아빠 모드 추천 3개
1. 이번 달 생활비 보드
2. TRC D-60 체크
3. 한국↔베트남 병원비 준비
```

현재 `누가 와도 바로 자기 이야기를 찾게` 섹션의 3개 카드를 더 인터랙티브하게 만드는 방향이다.

### TOP 5. 주말 가족 코스 룰렛, 단 ‘실제 조건 선택형’으로

- Visitor intent: “이번 주말 어디 가지?”, “아기 데리고 갈 만한 곳?”
- Retention mechanism: 날씨/아기 컨디션/예산을 선택하면 코스 추천
- Concrete section/card title: `이번 주말 가족 코스 뽑기`
- Why it increases dwell time: 룰렛은 즉시 눌러보고 싶지만, 조건형으로 만들면 유치하지 않고 실용적이다.
- Suggested visual asset: 지도 핀 3개 + 결과 코스 카드
- Future monetization angle: 키즈카페, 카페, 마트, 여행 준비물 가이드와 내부 링크. 향후 지역 콘텐츠 확장 가능
- Risk/trust note: 실제 영업시간/가격은 변동 가능하므로 확인 필요 표시

구성 예시:

```text
오늘 조건은?
날씨: [더움] [비] [괜찮음]
아기 컨디션: [활발] [졸림] [감기 조심]
예산: [아끼기] [보통] [기분전환]

결과: 비 오는 날 + 졸림 + 아끼기 → 몰 산책 + 간단한 장보기 + 집밥 루트
```

현재 `주말 코스` 링크와 `Family Mission`의 주말 버튼을 연결하면 좋다.

## 5. 첫 화면 구조 제안

현재 첫 화면은 설명과 카드가 먼저 보인다. 재미를 높이려면 첫 화면의 정보 밀도를 줄이고, 즉시 선택지를 올려야 한다.

추천 순서:

1. 한 줄 약속
   - `베트남에서 가족으로 사는 하루, 30초만에 오늘 볼 것을 골라보세요.`

2. 즉시 선택 위젯
   - `지금 제일 급한 것은? [돈] [아기] [서류] [주말]`

3. 선택 결과
   - 결과 문구 + 관련 페이지 CTA + 신뢰 라벨

4. 보조 카드
   - 오늘의 미션, 생활비 괴물 퀴즈, 체감 비교 슬라이더

5. 아래쪽에 신뢰 설명
   - 제작 노트, 업데이트 날짜, 경험 기반/공식 확인 필요 표시

즉, 첫 화면에서는 “우리가 무엇을 제공하는지”보다 “방문자가 무엇을 눌러야 하는지”가 먼저 보여야 한다.

## 6. 광고/수익화 관점에서의 배치

실제 광고 코드는 지금 넣지 않는 것이 맞다. 다만 미래 광고 슬롯이 자연스럽게 들어갈 위치는 설계할 수 있다.

1. 퀴즈 결과 아래
   - 생활비 괴물 결과 → 관련 생활비 가이드/도구 추천 영역
   - 광고보다 먼저 결과와 내부 링크 제공

2. 체크리스트 완료 후
   - 미션 완료 → 관련 가이드 CTA → 그 아래 콘텐츠 브레이크

3. 비교 슬라이더 아래
   - 한국 vs 베트남 비교 결과 → 더 자세한 표/가이드 → 미래 광고 슬롯

4. 주말 코스 결과 아래
   - 가족 코스 추천 → 준비물/지도/관련 글 → 콘텐츠 브레이크

주의: 첫 화면 위쪽에 광고 느낌의 박스가 먼저 보이면 신뢰가 깨진다. “쓸모를 준 다음” 자연스럽게 배치해야 한다.

## 7. 구현 난이도별 제안

### 1시간 안에 가능한 저비용 테스트

1. 현재 `mission-orbit` 문구를 더 직접적인 질문형으로 변경
   - 기존: `오늘은 어떤 문으로 들어갈까요?`
   - 제안: `지금 우리 가족에게 제일 급한 건?`

2. `missionResult`를 단순 설명이 아니라 결과 카드처럼 변경
   - `추천 루트`, `3분 행동`, `다음 링크` 포함

3. 체크리스트 제목을 미션형으로 변경
   - 기존: `이번 주 한-베 가족 체크리스트`
   - 제안: `오늘 1개만 끝내는 가족 미션`

### 반나절 테스트

1. 3문항 생활비 괴물 퀴즈 추가
2. 캐릭터 모드 선택 UI 추가
3. 한국 vs 베트남 체감 슬라이더 추가

### 이후 확장

2. 오늘의 미션 랜덤 표시
3. 한국어/베트남어/중국어 결과 문구까지 다국어화

5. 주말 코스 지도형 탐색 추가

## 8. 추천 우선순위

1. 생활비 괴물 찾기 퀴즈
   - 가장 클릭 유도 강함
   - 실용성과 재미가 동시에 있음
   - FamilySpace의 수익화 주제와 잘 맞음

2. 오늘 1개만 끝내는 가족 미션
   - 현재 체크리스트를 살리면서 재미를 만들 수 있음
   - 신뢰를 해치지 않음

3. 한국 vs 베트남 체감 슬라이더
   - 다국어 방문자에게도 직관적
   - 비교표보다 훨씬 덜 지루함

4. 캐릭터 모드 선택
   - FamilySpace만의 가족 캐릭터성을 강화
   - 내부 링크 루프에 좋음

5. 조건형 주말 코스 룰렛
   - 재미는 강하지만 실제 추천 데이터가 필요하므로 2차 적용 추천

## 9. 결론: 지금 index.html에 바로 넣을 재미 요소 3개

1. `생활비 괴물 찾기 3문항 퀴즈`
   - 첫 화면 또는 `today-lab` 바로 아래에 배치한다.
   - 방문자가 집세/마트/병원/아기용품/송금 중 하나를 고르면 “이번 달 우리집 생활비 괴물” 결과를 보여준다.
   - 결과에는 `자세한 생활비 보드 보기 → dad.html` 링크와 `경험 기반 점검용` 라벨을 붙인다.

2. `오늘 1개만 끝내는 가족 미션`
   - 현재 체크리스트를 미션 카드로 바꾼다.
   - 체크하면 완료 메시지와 다음 행동이 나타나게 한다.
   - 예: `TRC 날짜 저장`, `아기 병원 후보 저장`, `이번 주 장보기 3개 비교`.

3. `한국 ↔ 베트남 체감 비교 슬라이더`
   - 현재 비교표 위나 대신 넣는다.
   - 슬라이더/토글로 병원·마트·주말·아기 외식을 선택하면 체감 차이 문구가 바뀐다.
   - 숫자와 아이콘 중심이라 한국어/베트남어/중국어권 방문자 모두에게 과하지 않게 통한다.

이 3개는 광고판처럼 보이지 않으면서도 첫 화면의 ‘읽기만 하는 정보 페이지’ 느낌을 줄이고, 방문자가 직접 눌러보는 체류 이유를 만든다.
