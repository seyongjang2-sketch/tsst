# FamilySpace index.html Wild Minimal 제안

작업 범위: `/mnt/c/Users/Admin/tsst/index.html`을 직접 수정하지 않고, 현재 구조를 읽은 뒤 “복잡한 재미요소를 줄이고 Apple식 단순함 속에 FamilySpace다운 엉뚱함 하나만 남기는” 제안서를 작성했습니다.

## 1. 현재 인덱스 진단

현재 `index.html`은 좋은 의도와 유용한 요소가 많지만, 첫 화면에서 방문자가 동시에 너무 많은 것을 받습니다.

- 빠른 카드: TRC, 식단, 생활비, 주말 코스
- 사이드 카드: 많이 찾는 것, 인기 질문
- 방문자별 보드: 한국인, 베트남 가족, 중국어권
- Family Lab
- 미션 오비트
- 리빌 카드
- 체크리스트
- 비교표
- 다음 클릭 루프
- 제작 노트

문제는 “재미가 없다”가 아니라 “재미 후보가 너무 많아서 하나도 기억에 남기 어렵다”에 가깝습니다. Apple식으로 가려면 한 섹션에 한 메시지, 넓은 여백, 짧은 문장, 적은 선택지가 필요합니다.

## 2. 남길 단 하나의 엉뚱함

### Wild idea

“오늘의 가족 입국 도장”

방문자가 첫 화면에서 단 하나의 작은 선택을 합니다.

- 오늘 필요한 것: 돈 / 아기 / 서류 / 주말
- 선택하면 화면 중앙에 여권 도장처럼 짧은 결과가 찍힙니다.
- 예: “오늘은 서류국 입국 완료. TRC D-60 체크부터 보세요.”
- 결과 아래에는 단 하나의 링크만 보여줍니다.

이 엉뚱함은 현재의 `Family Mission`, `KR-VN 지도`, `다국어 가족`, `생활 체크리스트` 감성을 하나로 압축합니다. 여러 위젯을 다 남기지 않고, FamilySpace만의 기억 포인트 하나만 남기는 방식입니다.

## 3. 사용자 반응 목표

방문자가 느껴야 할 반응은 다음 하나입니다.

“아, 여기는 그냥 정보 사이트가 아니라 한국-베트남 가족이 직접 만든 작은 생활 여권 같은 곳이네.”

세부 반응:

- 한국인 방문자: “복잡하지 않고 바로 필요한 정보로 갈 수 있네.”
- 베트남 가족/배우자: “차갑지 않고 가족 느낌이 있네.”
- 중국어권 방문자: “긴 설명보다 선택지와 결과가 명확하네.”
- 재방문자: “오늘은 어떤 도장이 나올까?”라는 아주 작은 반복 이유가 생김.

## 4. 단순화된 페이지 구조 제안

### Section 1. Hero: 한 문장 + 한 선택

메시지:

“베트남에서 가족으로 살 때, 오늘 필요한 한 가지부터.”

구성:

- 큰 제목 1개
- 설명 1문장
- 언어 선택 KR / VI / 中文는 작고 조용하게 배치
- 중앙에 “오늘의 가족 입국 도장” 선택 버튼 4개
  - 돈
  - 아기
  - 서류
  - 주말

삭제 또는 축소할 것:

- hero floating note 3개
- hero quick card 4개
- 사이드 스택 2개
- 칩 6개
- 배경 문구/오브 과한 움직임

### Section 2. Today: 선택 결과가 이어지는 대표 카드 3개

메시지:

“가족 생활은 세 가지로 자주 돌아옵니다.”

카드:

1. 생활비
   - 링크: `dad.html`
   - 문구: “이번 달 돈이 어디로 갔는지 조용히 정리합니다.”

2. 식단과 육아
   - 링크: `mom.html` 또는 `baby.html`
   - 문구: “오늘 뭐 먹일지, 어디로 가야 할지부터 봅니다.”

3. 서류와 체크리스트
   - 링크: `guides/trc-visa-checklist.html`
   - 문구: “놓치면 피곤한 날짜를 먼저 잡습니다.”

현재의 audience board, quick guides, dashboard 일부를 이 3개 카드로 흡수합니다.

### Section 3. Family note: 신뢰를 조용히 보여주는 제작 노트

메시지:

“완성된 정답집이 아니라, 계속 고치는 가족 생활 노트입니다.”

구성:

- 최근 업데이트 날짜
- “우리 가족이 실제로 확인 중” 라벨
- 법률/의료/비자 정보는 공식 확인 필요하다는 짧은 체크포인트
- 다음 페이지로 가는 링크 3개

현재의 `trust-manifesto`는 유지하되 길이를 절반 이하로 줄입니다.

### CSS 방향

- 배경: 거의 흰색 또는 아주 연한 크림색
- 포인트 컬러: 한국 파랑 1개 + 베트남 따뜻한 빨강/노랑을 아주 적게
- 카드 그림자: 약하게
- 애니메이션: 도장이 찍히는 0.25초 scale/rotate 정도만
- 섹션 간 여백: 크게
- 한 화면에 보이는 선택지 수: 최대 4개

## 6. 왜 체류시간이 늘 수 있는가

- 선택 행동이 매우 작아서 부담이 낮습니다.
- 도장 결과가 즉시 나타나므로 첫 클릭 유도에 좋습니다.
- 결과가 내부 링크 하나로 이어져 다음 페이지 클릭 가능성이 높습니다.
- “오늘은 무엇을 고를까?”라는 반복 방문용 작은 의식이 됩니다.
- 현재 여러 인터랙션을 하나로 합쳐서, 방문자가 기억할 상징이 생깁니다.

## 7. 안전하고 tasteful하게 만드는 법

- 도장 결과를 과장하지 않습니다. “완벽 해결”, “필수”, “지금 안 하면 손해” 같은 문구 금지.
- 비자/의료/금융은 “가족 경험 기반, 공식 확인 필요” 라벨 유지.
- 여권/입국 콘셉트가 실제 정부 문서처럼 보이지 않게 장난감 도장 스타일로 만듭니다.
- 가족의 사생활을 팔아 보이기보다 “생활 노트” 감성으로 유지합니다.
- 광고나 수익화 문구는 첫 화면에 드러내지 않습니다.

## 8. 리스크

- 여권/입국 도장 콘셉트가 비자 정보와 섞이면 공식성으로 오해될 수 있습니다.
- 너무 귀엽게 만들면 Apple식 단순함보다 키즈 앱처럼 보일 수 있습니다.
- 선택 결과가 실제 콘텐츠로 이어지지 않으면 장난만 있고 실속이 없어 보입니다.
- 현재 있는 많은 콘텐츠를 과감히 숨겨야 해서, “정보량이 줄었다”는 내부 불안이 생길 수 있습니다.

대응:

- 도장은 “생활 여권”이 아니라 “가족 노트의 장난감 도장”으로 표현합니다.
- 디자인은 큰 여백, 얇은 선, 작은 이모지 정도로 절제합니다.
- 각 선택은 반드시 실제 내부 페이지 1곳으로 연결합니다.
- 상세 정보는 메인에서 설명하지 않고 하위 페이지로 이동시킵니다.

## 9. toned-down version

엉뚱함을 더 줄이고 싶다면 “입국 도장” 대신 “오늘의 한 가지” 카드로 갑니다.

이름:

“오늘의 한 가지”

동작:

- 돈 / 아기 / 서류 / 주말 중 하나 선택
- 아래에 짧은 추천 문장과 링크 표시
- 도장 그래픽 없이 얇은 라인 카드만 사용

문구 예시:

“오늘은 서류부터: TRC 날짜를 캘린더에 넣고 체크리스트를 확인하세요.”

이 버전은 더 Apple스럽고 안전하지만, FamilySpace만의 기억 포인트는 약해집니다.

## 10. 최종 추천

최종 추천은 “오늘의 가족 입국 도장”입니다.

단, 구현 시에는 다음 원칙을 지켜야 합니다.

1. 재미요소는 이 하나만 남긴다.
2. 첫 화면의 카드/칩/사이드보드 수를 크게 줄인다.
3. 한 섹션에는 한 메시지만 둔다.
4. 선택 결과는 반드시 내부 링크 하나로 이어진다.
5. 신뢰는 설명하지 말고 업데이트 날짜, 경험 기반 라벨, 공식 확인 체크포인트로 보여준다.

이 방향이면 FamilySpace의 한국-베트남 가족성은 유지하면서, 현재 인덱스의 복잡함을 Apple식 단순 구조로 낮출 수 있습니다.
