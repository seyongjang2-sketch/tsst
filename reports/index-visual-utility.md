주제: 정보 가독성과 화려함의 균형
대상 파일: `/mnt/c/Users/Admin/tsst/index.html`

## 1. 현재 index.html 진단

현재 index.html은 이미 단순한 가족 소개 페이지가 아니라 다음 요소를 갖춘 정보형 홈으로 구성되어 있다.

- 히어로: 한-베 가족 생활 지도, 빠른 길 카드, CTA, KR/VN/中文 지도 장식
- 방문자별 카드: 한국인/베트남인/중국어권 관심사 분리
- 체류 요소: Family Mission, 클릭형 생활 노트, 체크리스트, 비교표
- 내부 클릭 루프: dad.html, mom.html, baby.html, blog.html, 체크리스트 가이드
- 신뢰 요소: 제작 노트, 업데이트 예정, 경험 기반 라벨

강점:
- 정보 허브로서 방향은 좋다.
- 체크리스트, 비교표, 빠른 가이드, 다국어 버튼이 광고 수익형 페이지에 필요한 체류시간 구조와 맞는다.
- 한국인/베트남인/중국어권 방문자를 분리해 보여주는 점은 차별화 포인트다.

위험:
- 현재는 그라디언트, 오브, 글래스 카드, 플로팅 텍스트, 이모지, 지도 장식, 인터랙션이 이미 많다.
- 정보 페이지인데 배경 움직임과 장식이 과하면 “광고판/템플릿 사이트”처럼 보일 수 있다.
- 한국인 방문자에게는 신뢰와 정돈감이 약해 보일 수 있고, 중국어권 방문자에게는 정보 밀도는 좋지만 핵심 숫자/표가 더 선명해야 한다.
- 베트남인 방문자에게는 따뜻함은 있으나 실제 가족 이미지나 생활 사진감이 아직 부족하다.

결론:
현재 방향은 “밋밋함 1”이 아니라 이미 “화려함 3.5~4”에 가깝다. FamilySpace의 신뢰/가족/실용성을 유지하려면 최종 권장값은 화려함 3/5, 정보 밀도 4/5, 움직임 2/5가 적합하다.

## 2. 광고 수익형 페이지 관점의 필수 진단

### 2.1 누가 검색에서 들어오는가

1. 한국인 방문자
   - 베트남 생활비, 국제결혼 생활, TRC/비자, 베트남 육아, 병원, 장보기 정보를 찾는다.
   - 기대 감각: 깔끔함, 신뢰, 정돈된 표, 업데이트 날짜, 경험 기반이지만 과장 없는 문장.

2. 베트남인 방문자
   - 한-베 가족 일상, 아이 식단, 엄마의 루틴, 한국식 육아/생활 비교, 가족 분위기를 본다.
   - 기대 감각: 따뜻한 색감, 친근한 이미지, 가족감, 밝고 부드러운 카드.

3. 중국어권 방문자
   - 베트남 생활비/가족 여행/교육/병원/서류 정보를 빠르게 비교하고 싶어 한다.
   - 기대 감각: 정보 밀도, 숫자, 표, 명확한 CTA, 상업 사이트처럼 빠른 경로 안내.

### 2.2 어떤 문제/호기심으로 들어오는가

- “베트남에서 한-베 가족 생활비가 얼마나 들까?”
- “아기 병원/식단/마트는 어떻게 고를까?”
- “TRC, 비자, 서류는 언제 준비해야 할까?”
- “한국과 베트남의 육아/생활 차이는 실제로 어떤가?”
- “다른 한-베 가족은 어떻게 살고 있나?”

### 2.3 30초, 2분, 5분 체류 이유

30초 체류:
- 첫 화면의 빠른 카드 4개: TRC D-60, 아기 식단, 생활비, 주말 코스
- 한국/베트남/중국어권 카드로 “내 이야기” 발견

2분 체류:
- 생활비 비교표, 이번 주 체크리스트, 클릭형 생활 노트
- Family Mission에서 돈/육아/서류/주말 루트 선택

5분 체류:
- dad/mom/baby/blog로 이어지는 내부 클릭 루프
- 실제 가족 경험 기반의 업데이트 노트
- 향후 무료 체크리스트, 생활비 표, 병원 저장 목록

### 2.4 클릭할 수 있는 내부 경로

현재 경로는 적절하다.

- dad.html: 생활비, 금융, 베트남 생존 보드
- mom.html: 식단, 힐링 노트, 엄마 루틴
- baby.html: 성장 기록, 놀이, 잠, 병원
- blog.html: 가족 일기장
- guides/trc-visa-checklist.html: 무료 체크리스트

개선 방향:
- 각 카드에 “읽는 이유”를 더 짧고 강하게 넣는다.
- CTA는 감성 문구보다 구체적 행동형으로 만든다.
  - 예: “생활비 보드 보기”
  - 예: “TRC D-60 체크하기”
  - 예: “25개월 식단표 보기”

### 2.5 스크롤 보상 요소

현재 보상 요소:
- mission-orbit
- reveal-board
- checklist
- compare-table

추가하면 좋은 보상:

- KR/VN/CN별 추천 경로 미니맵

### 2.6 향후 광고 위치

실제 광고 코드는 넣지 말고, “future ad/content break” 자리만 설계하는 것이 좋다.

권장 위치:
1. 히어로 바로 아래가 아니라, 방문자별 관심사 카드 이후
2. Family Mission과 체크리스트 사이
3. 비교표 아래, 관련 가이드 CTA 위

피해야 할 위치:
- 첫 화면 CTA 위

- 아기/병원/비자처럼 민감한 정보 바로 옆의 과한 광고 박스

## 4. 추천 배경 스타일

### 권장: Soft Utility Map Background

배경은 “가족 생활 지도” 컨셉을 유지하되, 장식보다 정보 가독성을 우선한다.

구성:
- 기본 배경: 거의 흰색에 가까운 warm off-white
- 상단 히어로 뒤: 차분한 네이비-블루 그라디언트
- 전체 페이지: 아주 약한 지도/그리드 패턴
- 포인트 오브: 2~3개만, 불투명도 0.08~0.14 수준
- 움직임: 히어로 그라디언트 1개 또는 배경 오브 2개 이하

권장 CSS 감각:
- `#F8FBFF`, `#FFF8EE`, `#F6FAF7` 같은 밝은 배경
- grid line opacity는 0.025~0.04
- radial gradient opacity는 0.08~0.16
- fixed background 텍스트는 유지하되 opacity 0.025~0.035 이하

현재 코드의 `main-wrapper.home-lab::after` 대형 텍스트는 FamilySpace 정체성을 주지만, 모바일이나 정보 밀도가 높은 구간에서는 시선 방해가 될 수 있다. 유지한다면 현재보다 더 연하게 두는 것이 좋다.

## 7. 카드/사이드바/히어로 장식 강도

### 7.1 히어로

권장 강도: 3.5 / 5

유지하면 좋은 것:
- 큰 히어로 카드
- “오늘 바로 필요한 것” 빠른 카드
- KR/VN/中文 지도 시각화
- CTA 2개

줄이면 좋은 것:
- 플로팅 텍스트 3개는 1~2개로 제한
- motion-orbs는 4개에서 2~3개로 축소 권장
- 히어로 그라디언트 애니메이션은 너무 느리게 하거나 reduced-motion 외에도 모바일에서는 비활성화 권장

히어로의 목적:
방문자가 “예쁘다”보다 “내가 찾던 생활 정보가 여기 있다”를 먼저 느끼게 해야 한다.

### 7.2 카드

권장 강도: 3 / 5

카드 스타일:
- 흰색 배경 중심
- 1px 얇은 border
- 그림자는 현재보다 약간 줄인 `0 12px 32px rgba(16,42,67,.06~.08)` 수준
- 카드 안의 아이콘은 유지하되, 이모지만으로 정보 구분하지 않기
- `source-tag`, `updated-badge`, `difficulty badge` 같은 정보 라벨을 적극 활용

카드별 장식 강도:
- 한국인 카드: 가장 차분하게, 블루/네이비 중심
- 베트남인 카드: 코랄/옐로우 약간 더 허용
- 중국어권 카드: 색보다 숫자/표/CTA 강조

### 7.3 사이드바

권장 강도: 3 / 5

현재 사이드카드는 좋은 방향이다. 다만 “인기 질문”은 시각적으로 더 정보형이 되면 좋다.

권장 구성:
- 오늘 많이 보는 질문 TOP 3
- 난이도/소요시간/관련 페이지 배지
- 작은 progress bar는 유지 가능
- 스티키 사이드바는 데스크톱에서만 고려

예시:
- 생활비 정리 · 4분 · 비교표
- TRC D-60 · 6분 · 체크리스트
- 아기 병원 · 3분 · 지도 저장

### 7.4 애니메이션

권장 강도: 2 / 5

허용:
- hover 시 2~4px 이동
- reveal card 열림
- mission card 선택 효과
- 매우 느린 배경 이동 1개

줄이기:
- 클릭 spark는 재미는 있지만 정보형 사이트에서는 과하면 유치해 보일 수 있다. 남긴다면 데스크톱에서만, 크기/개수를 더 줄이는 편이 좋다.
- 계속 움직이는 요소가 3개 이상이면 글 읽기 방해가 된다.

## 8. 사용하면 좋은 이미지/일러스트 유형

### 8.1 권장 이미지 유형

1. 실제 생활 사진감
   - 장보기 바구니, 아기 식판, 가족 신발, 병원 수첩, 서류 파일, 주말 카페 테이블
   - 얼굴 노출이 없어도 가족감 전달 가능

2. 얇은 라인 일러스트
   - KR/VN 연결 지도
   - 체크리스트 아이콘
   - 생활비 항목 아이콘
   - 병원/마트/서류/식단 아이콘

3. 데이터형 미니 인포그래픽
   - 월 생활비 비율 도넛
   - 병원/식단/서류 난이도 바
   - 한국 vs 베트남 비교표

4. 다국어 키워드 태그
   - KR: 생활비, 비자, 육아
   - VI: gia đình, chi phí, em bé
   - 中文: 生活费, 签证, 宝宝

## 9. 피해야 할 디자인

1. 광고판형 홈
   - 첫 화면에 큰 배너, 과한 CTA, 번쩍이는 색상, 많은 배지
   - 위험: 가족 정보 사이트 신뢰도 하락

2. 너무 미니멀한 흰색 블로그
   - 정보는 읽히지만 기억에 남지 않고 내부 클릭이 약해진다.
   - 위험: 체류시간 부족

3. 유아용 앱 같은 톤
   - 이모지, 파스텔, 둥근 카드가 너무 많으면 육아 정보만 있는 사이트처럼 보인다.
   - 위험: 생활비/비자/서류 정보의 신뢰도 하락

4. 국적별 스테레오타입 과잉
   - 한국=차갑고 깔끔, 베트남=화려함, 중국=상업성처럼 단순화하면 위험하다.
   - 해결: 방문자별 “정보 탐색 방식” 차이로만 반영한다.

5. 움직임이 많은 랜딩페이지
   - 배경 오브, 그라디언트, floating note, spark, hover가 동시에 많으면 글을 읽기 어렵다.
   - 해결: 움직임은 선택/클릭 보상에 집중한다.

## 11. 바로 적용 가능한 시각 규칙 요약

### 배경

- 밝고 따뜻한 off-white 유지
- grid texture는 매우 약하게
- 큰 배경 텍스트는 opacity 0.025~0.035
- motion-orbs는 2~3개 이하

### 컬러

- 네이비/블루를 기본 신뢰축으로 사용
- 옐로우/코랄/그린은 감성 포인트로만 사용
- 중국어권 CTA는 orange/gold 포인트를 조금 허용하되 과한 빨강 사용은 피함

### 카드

- 카드 배경은 흰색 중심
- 그림자는 현재보다 약하게
- 라벨, 배지, 표, 체크리스트로 정보성을 강화
- 이모지는 보조 역할만

### 애니메이션

- hover/reveal 중심
- 지속 움직임은 최소화
- spark 효과는 선택적으로 축소 또는 제거 고려
- 모바일에서는 배경 애니메이션 거의 제거

### 이미지

- 실제 생활 소품 사진감 우선
- 얼굴 없는 가족 생활 컷도 충분히 좋음
- AI풍 가족 캐릭터보다 표/지도/체크리스트 인포그래픽이 더 적합

## 12. 최종 추천 방향

FamilySpace index.html은 “프리미엄 미니멀”도 아니고 “화려한 가족 랜딩페이지”도 아닌, 다음 포지션이 가장 적합하다.

> 따뜻한 가족 생활감이 있는 다국어 정보 지도형 홈

최종 값:

- 화려함: 3/5
- 정보 가독성: 4.5/5
- 따뜻함: 3.5/5
- 상업적 CTA 선명도: 3/5
- 애니메이션: 2/5
- 이미지 밀도: 2.5~3/5
- 카드/표/체크리스트 밀도: 4/5

핵심 판단:
- 한국인에게는 “믿을 수 있는 정리된 정보”처럼 보여야 한다.
- 베트남인에게는 “따뜻한 가족 이야기와 생활감”이 보여야 한다.
- 중국어권 방문자에게는 “표, 숫자, CTA, 빠른 이해”가 보여야 한다.
- 세 그룹을 모두 만족시키려면 배경을 더 화려하게 만들기보다, 카드 안의 정보 구조와 시각적 라벨을 더 똑똑하게 만드는 것이 좋다.

따라서 다음 수정 단계에서는 배경 장식을 추가하기보다, 현재 존재하는 `lab-audience`, `lab-dashboard`, `lab-loop`, `trust-manifesto`를 더 정돈된 정보 카드 시스템으로 통일하는 편이 가장 효과적이다.
