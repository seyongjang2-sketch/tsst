# Homepage Revision Roadmap - 2026-05-31

## 판단

홈페이지 수정은 한 번에 전면 교체하지 않는다. 현재 사이트는 이미 여러 페이지, 운영 콘솔, 일일/주간 업데이트, 가이드, 정책 페이지, 외부 링크가 섞여 있으므로 수정 범위를 작은 배치로 나누어 검증 가능한 순서로 진행한다.

## 수정 원칙

1. 먼저 고객이 보는 흐름을 단순화한다.
2. 중복되거나 목적이 약한 콘텐츠를 줄인다.
3. 링크, 이미지, 모바일 화면, 공개 테스트 URL 검증을 각 배치마다 완료한다.
4. 비자, 의료, 금융, 광고, 개인정보 문구는 검증 전 단정적으로 쓰지 않는다.
5. 각 배치는 변경 파일, 수락 기준, 스크린샷, 공개 테스트 확인 결과를 프로젝트 로그와 Telegram에 남긴다.

## 1차: 홈페이지 첫 화면과 핵심 경로 정리

- 대상: `index.html`, 공통 내비게이션, 첫 화면, 층별 진입 링크
- 목표: 방문자가 5초 안에 "누구를 위한 사이트인지", "어디를 눌러야 하는지", "아직 private test인지" 이해하게 만든다.
- 작업:
  - 첫 화면 문구를 한-베 가족 생활 운영 사이트로 명확화
  - 층별 카드/집 인터랙션의 목적과 진입 링크 정리
  - 운영 콘솔이 고객에게 과하게 내부 업무처럼 보이는지 판단 후 축소 또는 하단 이동
  - 모바일 첫 화면에서 내비게이션, 집 이미지, 버튼이 겹치지 않는지 확인
- 수락 기준:
  - 모바일 390px, 데스크톱에서 첫 화면 겹침 없음
  - 1층/2층/3층/4층/옥상 링크가 모두 정상 이동
  - private test 문구가 보이되 사이트 목적을 가리지 않음

## 2차: 페이지별 역할 재정의

- 대상: `mom.html`, `baby.html`, `dad.html`, `blog.html`, `stars.html`
- 목표: 각 페이지가 겹치지 않는 역할을 갖게 만든다.
- 작업:
  - 엄마: 식단, 장보기, 회복 루틴 중심
  - 아기: 5분 놀이, 기록, 부모 체크 중심
  - 아빠: 생활비, 송금, TRC/서류, 가족 일정 중심
  - 가족: 가족 기록, 공유 글감, 생활 가이드 연결 중심
  - 옥상: 하루 마무리, 아이와 대화, 별보기 체험 중심
  - 각 페이지에서 다른 층과 중복되는 카드나 오래된 취미성 콘텐츠 제거 후보 표시
- 수락 기준:
  - 각 페이지의 H1/H2와 주요 CTA가 페이지 역할과 일치
  - 같은 내용을 다른 페이지에서 반복 설명하지 않음
  - 고객이 다음 행동을 하나 이상 명확히 찾을 수 있음

## 3차: 콘텐츠 신뢰도와 날짜 기준 정리

- 대상: 일일/주간 업데이트 섹션, 가이드 링크, 외부 링크
- 목표: "매일 업데이트"처럼 보이는 문구가 실제 날짜, 실제 변경 내용, 근거와 맞게 보이게 만든다.
- 작업:
  - 오래된 날짜가 박힌 운영 문구 정리
  - 오늘/이번 주 표현을 실제 운영 날짜와 맞추거나 evergreen 문구로 변경
  - 비자/TRC, 예방접종, 송금/생활비 문구의 주의 문구와 검증 필요 항목 표시
  - 외부 링크는 실제 클릭 후 목적이 맞는지 확인
- 수락 기준:
  - 날짜가 지난 "오늘" 문구가 방치되지 않음
  - 외부 링크가 HTTP/브라우저 기준으로 접근 가능
  - 고위험 문구는 조언이 아니라 체크리스트/참고 정보로 표현

## 4차: 모바일 UX와 공통 UI 정리

- 대상: `style.css`, 페이지별 인라인 스타일, 공통 내비게이션, 버튼/카드
- 목표: 페이지마다 다른 스타일이 누적되어 보이는 문제를 줄이고 모바일 사용성을 맞춘다.
- 작업:
  - 반복 내비게이션 구조 통일
  - 인라인 스타일 축소 후보 정리
  - 카드 안 카드, 과도한 장식, 긴 문장으로 인한 넘침 확인
  - 버튼 라벨과 링크 목적 일치 확인
- 수락 기준:
  - 주요 페이지 모바일 스크린샷에서 텍스트 겹침 없음
  - 공통 메뉴가 모든 페이지에서 같은 순서와 같은 라벨 사용
  - 버튼을 눌렀을 때 라벨과 이동 결과가 일치

## 5차: 운영/배포 검증 게이트 강화

- 대상: `scripts/autonomous_ops_loop.py`, `reports/ops_extended_check.spec.js`, 운영 문서
- 목표: 현재 자동 점검에 부족한 "실제 클릭, 내용 일치, 중복/불필요 콘텐츠" 검토를 운영 게이트로 추가한다.
- 작업:
  - 모든 주요 CTA 클릭 테스트 추가
  - 핵심 외부 링크 샘플 접속 확인 추가
  - 페이지별 핵심 문구 존재/중복 여부 체크 추가
  - 수정 배치별 screenshot evidence 저장 규칙 정리
- 수락 기준:
  - 로컬 HTML 파싱, 링크/이미지 경로, Playwright 모바일/데스크톱 검증 통과
  - Cloudflare 기술 검증 URL에서 변경 문구 확인
  - 실패 시 완료가 아니라 보류/차단으로 보고

## 진행 순서

1. 1차 홈페이지 첫 화면 정리
2. 2차 페이지별 역할 정리
3. 3차 콘텐츠 신뢰도/날짜 정리
4. 4차 모바일 UI 정리
5. 5차 운영 검증 자동화 보강

각 단계는 별도 작업 단위로 진행한다. 한 단계가 끝날 때마다 변경 파일, 검증 명령, 스크린샷, 남은 문제를 기록한 뒤 다음 단계로 넘어간다.
