# Lotto Number Generator

## Overview

This application generates a set of 6 unique random numbers for a lottery drawing, similar to the Korean Lotto 6/45.

## Features

*   **Number Generation:** Generates 6 unique random numbers between 1 and 45.
*   **Display:** Displays the generated numbers in a clean, user-friendly interface.
*   **User Interaction:** A button allows the user to generate a new set of numbers at any time.

## Design

*   **Layout:** A centered, card-based layout.
*   **Typography:** Clear, legible fonts with a strong headline.
*   **Color Scheme:** A modern and visually appealing color palette will be used. Numbers will be color-coded based on their range.
*   **Interactivity:** The "Generate" button will have clear hover and active states.
