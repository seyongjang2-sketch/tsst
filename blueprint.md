# Lotto Number Generator

## Overview

This application generates a set of 6 unique random numbers for a lottery drawing, similar to the Korean Lotto 6/45. It is designed to be visually appealing, mobile-friendly, and provides a premium user experience.

## Features

*   **Multi-Game Generation:** Generate 1, 5, or 10 sets of numbers at once.
*   **Visual Color Coding:** Numbers are color-coded based on their value range (1-10: Yellow, 11-20: Blue, 21-30: Red, 31-40: Grey, 41-45: Green).
*   **Animation:** Smooth staggered "pop-in" animation for the lotto balls.
*   **Dark/Light Mode:** Full support for dark and light themes with persistent settings.
*   **Essential Pages:** Includes About, Terms of Service, Privacy Policy, and Contact pages for AdSense compliance.
*   **Reset Functionality:** Easily clear generated numbers with a "Clear" button.
*   **Game Labels:** Multi-game results are labeled (Game A, Game B...) for clarity.

## Design

*   **Layout:** Modern card-based UI with a fixed navigation bar and a informative footer.
*   **Typography:** Professional font pairing using 'Montserrat' for headers and 'Noto Sans KR' for body text.
*   **Responsive:** Fully responsive design that works on desktops, tablets, and mobile devices.

## Implementation Details

*   **HTML5/CSS3:** Semantic markup and modern CSS variables for theme management.
*   **JavaScript:** Asynchronous generation logic with staggered delays for enhanced visual effect.
*   **Local Storage:** Used for theme persistence.
