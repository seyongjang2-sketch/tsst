개인정보처리방침 (Chính sách Bảo mật)

1. 수집하는 개인정보 (Thông tin thu thập)

FamilySpace는 사용자가 블로그 댓글을 남기거나 문의할 때 필요한 최소한의 정보만을 수집합니다.
FamilySpace chỉ thu thập các thông tin tối thiểu cần thiết khi người dùng để lại bình luận trên blog hoặc liên hệ.

2. 개인정보의 이용 목적 (Mục đích sử dụng)

수집된 정보는 서비스 개선 및 가족 간의 원활한 소통을 위해서만 사용됩니다.
Thông tin thu thập được chỉ được sử dụng để cải thiện dịch vụ và giao tiếp suôn sẻ giữa các thành viên trong gia đình.

3. 구글 애드센스 광고 (Quảng cáo Google AdSense)

본 웹사이트는 구글 애드센스 광고를 송출할 수 있으며, 쿠키를 사용하여 사용자의 방문 기록을 분석합니다.
Trang web này có thể phân phối quảng cáo Google AdSense và sử dụng cookie để phân tích hồ sơ truy cập của người dùng.

4. 베트남 광고법 준수 (Tuân thủ Luật Quảng cáo Việt Nam)

FamilySpace는 베트남 시행령 Decree 342 및 관련 광고법을 준수합니다.
FamilySpace tuân thủ Nghị định 342 và các luật quảng cáo liên quan tại Việt Nam.

5. Google OAuth 및 YouTube API 데이터 처리

FamilySpace는 사용자가 명시적으로 승인한 경우에만 Google OAuth 또는 YouTube API 기능을 사용합니다. 이 기능은 사용자가 요청한 YouTube 업로드, 비공개 테스트, 채널 관련 작업을 수행하기 위한 목적으로만 사용됩니다.

OAuth를 통해 처리될 수 있는 데이터는 Google 계정 식별 정보, 사용자가 승인한 YouTube 채널 권한, 사용자가 직접 제공하거나 승인한 영상 파일, 제목, 설명, 공개 범위 등 업로드 관련 메타데이터입니다. FamilySpace는 승인된 목적 외의 광고, 판매, 제3자 마케팅 목적으로 Google 사용자 데이터를 사용하지 않습니다.

FamilySpace는 사용자의 명시적인 실행 또는 승인 없이 YouTube 영상을 공개 업로드하거나 채널 정보를 변경하지 않습니다. 자동화 도구가 사용되더라도 업로드, 공개, 삭제, 공개 범위 변경 같은 외부 작업은 사용자의 별도 지시가 있는 경우에만 수행됩니다.

사용자는 언제든지 Google 계정 권한 페이지(https://myaccount.google.com/permissions)에서 FamilySpace의 접근 권한을 해제할 수 있습니다. 권한 해제 후 관련 데이터 삭제가 필요한 경우 FamilySpace 문의 채널을 통해 요청할 수 있습니다.

FamilySpace의 Google API 데이터 사용 및 전송은 Google API Services User Data Policy와 Limited Use 요구사항을 준수합니다.
