# FamilySpace 조직도

## 지휘 체계

```text
운영 총괄 관리자 윤재
├─ 수익화 관리자 태준
├─ 아이디어팀 리드 지윤
│  ├─ 가족 생활 아이디어 담당 민호
│  ├─ 콘텐츠 시리즈 담당 서연
│  ├─ 신선한 아이디어 담당 라라
│  └─ 수익화 아이디어 담당 태오
├─ 디자인팀 리드 하린
│  ├─ UX/레이아웃 디자이너 도윤
│  └─ 비주얼 에셋 디자이너 유나
├─ 웹 관리자 준호
├─ 콘텐츠 에디터 은서
├─ SEO 분석가 현우
└─ QA 리뷰어 수빈
```

## 의사결정 라인

| 단계 | 담당 | 승인 기준 |
| --- | --- | --- |
| 1 | 아이디어팀 | 독자 가치, 실행 난이도, 신뢰 리스크를 기준으로 후보를 만든다. |
| 2 | 콘텐츠 에디터 | 경험담, 정보성 문장, 공식 확인 필요 문구를 정리한다. |
| 3 | SEO 분석가 | 검색 의도, 제목, 설명, 내부 링크를 점검한다. |
| 4 | 디자인팀 | 모바일 가독성, 정보 위계, 이미지 방향을 승인한다. |
| 5 | 웹 관리자 | HTML/CSS/JS 반영과 링크, 파일 구조를 점검한다. |
| 6 | QA 리뷰어 | 반응형, 링크, 오탈자, 정책 리스크를 검사한다. |
| 7 | 운영 총괄 관리자 | 공개 여부와 우선순위를 최종 승인한다. |
| 8 | 수익화 관리자 | 광고, 제휴, 분석, 정책 위험을 최종 확인한다. |

## 팀별 책임

| 팀 | 구성원 | 핵심 책임 |
| --- | --- | --- |
| 총괄 | 윤재, 태준 | 우선순위, 승인, 수익화, 정책 리스크 |
| 아이디어팀 | 지윤, 민호, 서연, 라라, 태오 | 콘텐츠/기능/참여/수익화 아이디어 발굴 |
| 디자인팀 | 하린, 도윤, 유나 | 브랜드 톤, 모바일 UX, 이미지/썸네일 방향 |
| 운영 | 준호, 은서, 현우, 수빈 | 사이트 구현, 편집, SEO, QA |

세부 전문지식과 페르소나는 `agents/staff_profiles.json`을 기준으로 한다.
