# 리서치 반영 아이디어 보드: 소셜 유행을 FamilySpace에 녹이기

일시: 2026-05-26  
목표: 베트남 Facebook/Zalo/TikTok 흐름과 한국 Instagram/Naver/YouTube 흐름을 FamilySpace 첫 화면, 콘텐츠, 디자인에 반영한다.

## 핵심 전략

FamilySpace의 콘텐츠는 앞으로 하나의 글로 끝나지 않는다. 글 하나를 만들 때마다 다음 4개 포맷을 같이 만든다.

1. 웹 글: 검색과 자세한 설명용
2. 저장 카드: Instagram/KakaoTalk/Zalo에 보내기 좋은 한 장 요약
3. 공유 체크리스트: Facebook/Zalo 그룹에 올리기 좋은 실용 정보
4. 숏폼 아이디어: TikTok/YouTube Shorts로 바꿀 수 있는 15-30초 구성

## 첫 화면에 녹일 큰 아이디어

### 1. 오늘 저장할 카드

방문자가 첫 화면에서 바로 저장하고 싶어지는 카드 3장을 보여준다.

- 병원 가방 카드
- TRC D-60 카드
- 이번 주 생활비 카드

디자인:

- Instagram처럼 저장하고 싶은 정사각형 카드
- Zalo로 가족에게 보내도 어색하지 않은 실용 문장
- 카드 안에는 숫자와 체크 항목을 크게 보여준다

### 2. 가족 상황별 입구

검색어가 아니라 현재 상황으로 들어오게 한다.

- 아이가 아파요
- 이번 달 지출이 커요
- 서류가 급해요
- 주말 갈 곳이 필요해요

소셜 연결:

- Facebook 질문글 같은 느낌
- 누르면 바로 답을 주는 구조
- 나중에 댓글/커뮤니티 질문으로 확장 가능

### 3. 공유하기 좋은 체크리스트

첫 화면 아래에 "가족에게 보내기 좋은 체크리스트" 영역을 만든다.

- 아이 병원 가방 7개
- TRC 준비 5단계
- 베트남 마트 장보기 6칸

소셜 연결:

- Zalo 가족방에 보내기 좋은 톤
- Facebook 그룹에 공유하기 좋은 제목
- 이미지 카드로 캡처하기 쉬운 구성

### 4. 주말 룰렛

날씨, 예산, 아이 컨디션을 고르면 주말 코스를 추천한다.

선택지:

- 날씨: 더움 / 비 / 선선함
- 예산: 낮음 / 보통 / 여유
- 아이 컨디션: 낮잠 전 / 에너지 많음 / 조용한 날

결과 예:

- "마트 + 실내 키즈카페 + 짧은 간식"
- "공원 30분 + 카페 + 집밥"
- "가까운 몰 + 장보기 + 아이 낮잠"

소셜 연결:

- Instagram Story 투표처럼 가볍게 누르는 느낌
- TikTok/Shorts로 "오늘의 주말 루트" 만들기 좋음

### 5. 생활비 감각 계산기

월세, 마트, 병원비, 아이 용품을 입력하면 이번 달 감각을 보여준다.

결과 예:

- "이번 달은 병원비가 커진 달입니다."
- "마트 지출이 커졌습니다. 다음 주 장보기 메모를 먼저 보세요."
- "월세 제외 생활비를 따로 보면 더 정확합니다."

소셜 연결:

- Naver 검색형 긴 글과 잘 맞음
- Instagram 카드로 "생활비 5칸 정리" 확장 가능

### 6. 오늘의 베트남어 카드

병원, 어린이집, 마트에서 바로 쓰는 베트남어 한 문장을 보여준다.

예:

- "Con bị sốt." 아이가 열이 있어요.
- "Bé ăn được không?" 아이가 먹을 수 있나요?
- "Cho tôi hóa đơn." 영수증 주세요.

소셜 연결:

- Zalo/KakaoTalk으로 가족에게 보내기 좋음
- Instagram 저장형 카드로 만들기 좋음

### 7. TRC D-day 메모

만료일을 넣으면 D-60, D-30, D-7에 해야 할 일을 보여준다.

주의:

- 법률 조언처럼 보이면 안 된다.
- "반드시 공식 기관/전문가 확인" 문구를 함께 보여준다.

소셜 연결:

- Facebook 그룹에서 질문이 많은 주제
- Naver 검색 유입 가능성이 큼

## 팀원별 새 아이디어

### 지윤: 구조화 아이디어

1. 홈을 "오늘 고르기 -> 카드 보기 -> 자세히 보기" 흐름으로 재구성
2. 모든 콘텐츠에 `웹 글 / 저장 카드 / 공유 체크리스트 / 숏폼` 태그 부여
3. 첫 화면에는 기능 3개만 강하게 노출: 카드, 상황별 입구, 플레이 보드
4. 하단에는 인기 메모와 최신 업데이트를 배치
5. 광고 슬롯은 정보 카드 사이가 아니라 섹션 끝에 자연스럽게 배치

### 민호: Facebook/Zalo형 실용 아이디어

1. "한-베 가족 병원 가방 7개"
2. "TRC 만료 전 가족이 확인할 5가지"
3. "호치민 마트 장보기 6칸"
4. "어린이집 알림장 자주 나오는 베트남어"
5. "베트남 집 계약 전 확인 10개"
6. "아이 열날 때 기록할 4가지"
7. "가족 보험 카드에 적어둘 6가지"
8. "이번 주 장보기 메모"
9. "한 달 공과금 날짜표"
10. "병원 다녀온 뒤 약 기록표"

### 서연: Instagram/Naver 변환 아이디어

1. 웹 글: 호치민 가족 생활비 실제 항목
   - 카드: 생활비 5칸 정리
   - 체크리스트: 이번 달 지출 확인표
   - 숏폼: 한 달 생활비 30초 요약

2. 웹 글: 아이 병원 가방 준비
   - 카드: 병원 가방 7개
   - 체크리스트: 병원 가기 전 1분 확인
   - 숏폼: 가방에 넣을 것 7개

3. 웹 글: TRC D-60 준비
   - 카드: D-60, D-30, D-7
   - 체크리스트: 서류 확인표
   - 숏폼: TRC 준비 3단계

4. 웹 글: 주말 가족 루트
   - 카드: 더운 날 / 비 오는 날 / 조용한 날
   - 체크리스트: 외출 전 준비물
   - 숏폼: 오늘의 가족 루트

라라의 1순위 추천:

`주말 룰렛`은 재미와 정보의 균형이 가장 좋다. 첫 화면에 넣어도 부담이 적고, Instagram/TikTok 감각으로 확장하기 쉽다.

### 태오: 수익화 연결 아이디어

1. 생활비 계산기 아래에 나중에 금융/송금/보험 광고 후보
2. 병원 체크리스트 아래에 병원/보험/약국 제휴 후보
3. 주말 룰렛 아래에 키즈카페/마트/카페 제휴 후보
4. TRC D-day 아래에 행정 대행/번역/공증 서비스 후보
5. 베트남어 카드 아래에 언어 수업/교재 제휴 후보

원칙:

- 지금은 광고 코드를 넣지 않는다.
- 먼저 신뢰형 도구와 저장형 카드를 만든다.
- 광고는 나중에 자연스럽게 들어갈 자리만 설계한다.

## 디자인팀 제안

### 첫 화면 구성안

1. Hero: FamilySpace 정체성
2. 오늘의 플레이 보드: 버튼으로 만지는 재미
3. 오늘 저장할 카드: Instagram/Zalo 감각
4. 가족 상황별 입구: Facebook 질문글 감각
5. 자세히 보기: 웹 글과 검색형 콘텐츠

### 카드 디자인 기준

- 정사각형 또는 4:5 비율로도 잘라 쓸 수 있게 만든다.
- 제목은 12자 안팎으로 짧게 쓴다.
- 숫자를 크게 보여준다.
- 본문은 3-5개 체크 항목으로 제한한다.
- 색은 너무 귀엽게 가지 않고, 따뜻한 종이/메모 톤을 유지한다.
