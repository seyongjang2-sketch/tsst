# 층별 콘텐츠 아이디어 회의 - 2026-05-26

## 회의 목표
첫 화면의 집 구조와 연결되는 각 방 페이지에 실제로 볼거리와 눌러볼 거리를 채운다. 방문자가 글만 읽는 느낌이 아니라, 방에 들어가서 하나씩 열어보는 느낌을 받게 한다.

## 아이디어팀 결론
- 1층 엄마 공간: 식단, 장보기, 짧은 요가, 오늘의 휴식 루틴을 바로 실행할 수 있게 만든다.
- 2층 아기 놀이방: 아이와 5분 안에 할 수 있는 놀이, 한국어/베트남어 단어, 성장 기록을 중심으로 만든다.
- 3층 아빠 작업실: 비자/TRC, 생활비, 송금, 보험, 서류 마감일을 한눈에 보이게 만든다.
- 4층 가족 거실: 가족 이야기, 주말 회고, 공개 블로그 글감, 가족 앨범을 모으는 공간으로 만든다.
- 옥상 별보기: 별자리 체험, 오늘 밤 미션, 아이에게 들려줄 짧은 과학 이야기를 넣는다.

## 디자인팀 결론
- 각 페이지 첫 화면에는 “방 이름 + 오늘 할 일 + 추천 카드 3개”를 공통 구조로 둔다.
- 색은 층마다 다르게 하되 기존 페이지 톤을 깨지 않는다.
- 카드에는 긴 설명보다 행동 문장, 짧은 설명, 다음 링크를 넣는다.
- 광고 수익화는 나중에 붙일 수 있도록 “추천 도구/체크리스트/자료 다운로드” 자리를 남긴다.

## 총괄 결정
각 하위 페이지 상단에 `room-brief` 섹션을 추가한다. 기존 기능은 삭제하지 않고, 새 방문자가 페이지에 들어오자마자 이 방에서 무엇을 볼 수 있는지 이해하게 만든다.
