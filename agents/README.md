# FamilySpace 운영 조직

FamilySpace를 꾸준히 관리하고, 꾸미고, 콘텐츠 아이디어를 만들고, 광고 수익화까지 준비하기 위한 가상 운영팀입니다.

## 기준 문서

- `agents/staff_profiles.json`: 전 직원 전문지식, 페르소나, 산출물, 로그 의무
- `agents/page_knowledge_injections.md`: 페이지별 직원 지식 주입 노트와 웹 확인 출처
- `agents/org_chart.md`: 사람이 읽는 조직도와 승인 흐름
- `agents/logging_protocol.md`: 프로젝트 로그 작성 규칙
- `agents/project_log.md`: 로그만으로 프로젝트 현황을 파악하기 위한 단일 운영 로그

## 핵심 원칙

- 가장 중요한 역량은 아이디어와 디자인입니다.
- 아이디어는 한 명이 아니라 5명 팀이 서로 다른 관점으로 제안합니다.
- 디자인은 3명 팀이 브랜드, 화면, 이미지 방향을 나누어 관리합니다.
- 광고보다 먼저 신뢰를 쌓습니다. 경험담, 생활 정보, 공식 확인 경로, 개인정보/약관 페이지를 우선 관리합니다.
- 디자인 변경은 모바일 화면을 먼저 확인합니다.
- 모든 의미 있는 작업은 `agents/project_log.md`에 남깁니다. 작업자, 결정, 변경 파일, 검증 방법, 남은 위험, 다음 액션이 없는 작업은 완료로 보지 않습니다.

## 아이디어팀 5명

| ID | 역할 | 관점 |
| --- | --- | --- |
| `idea_lead` | 아이디어팀 리드 | 전체 아이디어 회의 진행, 우선순위 정리 |
| `family_life_ideator` | 가족 생활 아이디어 담당 | 한-베 가족의 일상 문제와 루틴 |
| `content_series_ideator` | 콘텐츠 시리즈 담당 | 저장하고 다시 보는 연재형 글감 |
| `community_ideator` | 커뮤니티 아이디어 담당 | 댓글, 참여, 질문, 가족 이야기 |
| `revenue_ideator` | 수익화 아이디어 담당 | 광고, 제휴, 상품, 체크리스트형 수익화 |

## 디자인팀 3명

| ID | 역할 | 관점 |
| --- | --- | --- |
| `design_lead` | 디자인팀 리드 | 전체 브랜드 톤과 디자인 승인 |
| `ux_layout_designer` | UX/레이아웃 디자이너 | 모바일 화면, 정보 구조, 버튼/섹션 배치 |
| `visual_asset_designer` | 비주얼 에셋 디자이너 | 이미지 방향, 썸네일, 광고 슬롯 주변 시각 정리 |

## 기본 작업 흐름

1. 아이디어팀 5명이 각자 관점에서 제안합니다.
2. 아이디어팀 리드가 중복을 제거하고 상위 후보를 정리합니다.
3. 콘텐츠 에디터와 SEO 분석가가 글감과 검색 의도를 정리합니다.
4. 디자인팀 3명이 화면 구성, 이미지, 모바일 UX 방향을 나눠 검토합니다.
5. 웹 관리자가 사이트에 반영합니다.
6. QA 리뷰어가 모바일, 링크, 정책, 광고 적합성을 확인합니다.
7. 운영 총괄 관리자가 공개 여부를 승인합니다.
8. 수익화 관리자가 광고/제휴/분석 결과를 추적합니다.

## 이번 달 우선순위

1. 아이디어팀이 FamilySpace 콘텐츠 아이디어 50개 만들기
2. 디자인팀이 홈, 아빠, 엄마, 아이, 블로그 페이지의 디자인 방향 정리
3. FamilySpace 기준으로 README와 오래된 로또 관련 페이지 정리
4. AdSense 신청 전 필수 페이지 점검: 소개, 문의, 개인정보처리방침, 이용약관
5. 광고 슬롯 위치 후보 설계
