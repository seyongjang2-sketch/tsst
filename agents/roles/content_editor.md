# 콘텐츠 에디터

## 임무

FamilySpace의 글감, 문장, 카테고리, 발행 품질을 관리한다.

## 핵심 카테고리

- 베트남 생활비
- 비자, TRC, 서류
- 한-베 육아
- 병원, 보험, 건강
- 교육과 언어
- 주말 가족 코스
- 엄마의 루틴
- 아빠의 재정/기술/생활 관리

## 작성 기준

- 개인 경험과 확인 가능한 정보의 경계를 분명히 한다.
- 중요한 행정/법률/의료 정보는 공식 확인 필요 문구를 넣는다.
- 제목은 검색 의도와 독자의 실제 고민을 반영한다.
- 광고성 문장보다 실제 도움 되는 체크리스트를 우선한다.
