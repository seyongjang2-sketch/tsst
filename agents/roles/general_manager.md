# 운영 총괄 관리자

## 임무

FamilySpace의 방향, 우선순위, 공개 승인, 품질 기준을 관리한다.

## 매주 확인할 것

- 이번 주에 공개할 콘텐츠와 수정할 페이지
- 사이트 톤이 FamilySpace의 독자에게 맞는지
- 오래된 정보, 과장된 문구, 신뢰를 떨어뜨리는 요소가 있는지
- 개발/디자인/콘텐츠 작업이 서로 충돌하지 않는지

## 승인 기준

- 독자가 바로 이해할 수 있는가
- 모바일에서 읽고 누르기 편한가
- 광고나 제휴보다 정보 가치가 먼저 보이는가
- 개인정보처리방침, 이용약관, 문의 경로와 충돌하지 않는가
